# Gabriela Felgueiras - Portfolio

My personal space on the web, where I share my projects, experiences, and a little more about myself beyond the code.

**[View Live Portfolio ↗](https://gabrielaaf.vercel.app)**

## About

I built this portfolio to bring together my technical and creative sides. I wanted something simple, personal, and interactive that reflects both the work I've done and the things I'm passionate about.

Designed and developed from scratch using **React, TypeScript, and CSS Modules**.

## Features & Interactions

- **Light and Dark Themes:** Switch between two color palettes, with the selected theme persisted using `localStorage`.
- **Responsive Design:** Layouts adapt across desktop, tablet, and mobile screens.
- **Animated Navigation:** A slide-out menu with keyboard focus management, Escape-to-close behavior, and background scroll locking.
- **Interactive Work Showcase:** Select projects to update their details, browse screenshots when available, and follow repository links.
- **Scroll-Triggered Animations:** `IntersectionObserver` reveals sections and timeline entries as they enter the viewport.
- **Beyond the Code:** An interactive conversation where messages can be revealed through scrolling, swiping, keyboard interactions, or a continue button.
- **Accessibility:** Semantic HTML, descriptive labels, visible focus states, keyboard interactions, and support for `prefers-reduced-motion`.
